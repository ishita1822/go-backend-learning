# Go Backend Learning

A structured learning repository for Go backend engineering, clean code, SOLID principles, Low-Level Design (LLD), System Design, and Data Structures and Algorithms (DSA).

## Learning Roadmap

### 1. Go Fundamentals

Core Go concepts, interfaces, error handling, concurrency, and best practices.

- [Interfaces](./go-fundamentals/interfaces.md)
- **Planned:** Error handling, goroutines, channels, context, synchronization, and testing.

### 2. OOP Concepts

Object-oriented programming concepts and how they translate to Go, including composition, encapsulation, abstraction, and polymorphism.

**Status:** Planned

### 3. SOLID Principles

Learn the five SOLID principles with practical Go and backend engineering examples.

- [Single Responsibility Principle (SRP)](./solid-principles/single-responsibility-principle.md)
- **Planned:** Open/Closed Principle (OCP), Liskov Substitution Principle (LSP), Interface Segregation Principle (ISP), and Dependency Inversion Principle (DIP).

### 4. Design Principles

Dependency Injection, constructor functions, separation of concerns, and maintainable code.

- [Constructor Functions](./design-principles/constructors.md)
- [Dependency Injection](./design-principles/dependency-injection.md)

### 5. Design Patterns

Reusable solutions to common software design problems, with practical Go examples.

**Status:** Planned

### 6. Low-Level Design (LLD)

Practice designing backend components and services, defining interfaces, managing dependencies, and applying design principles.

**Status:** Planned

### 7. System Design

Study scalable architectures, databases, caching, messaging, distributed systems, and reliability.

**Status:** Planned

### 8. Data Structures and Algorithms (DSA)

Pattern-based problem solving, starting with brute-force approaches and progressing to optimized solutions, including time and space complexity analysis.

**Status:** Planned

## Learning Method

Each topic will include, where applicable:

- A clear interview-ready definition and simple explanation.
- Go code examples and practical backend use cases.
- Step-by-step problem solving and code walkthroughs.
- Time and space complexity analysis.
- Practice questions, assessments, and interview takeaways.

## Goal

Build strong Go backend engineering, LLD, System Design, and interview problem-solving skills through consistent, hands-on practice.

This repository will grow progressively as each topic is studied, implemented, and reviewed.
